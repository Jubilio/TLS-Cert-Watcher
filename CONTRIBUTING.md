# Contributing

1. Create a focused branch from `main`.
2. Install dependencies with `npm ci --legacy-peer-deps`.
3. Make the change and add or update tests.
4. Run `npm run ci` locally.
5. Open a pull request describing the problem, solution, security implications, and verification performed.

Please keep unrelated refactors out of the same pull request. Security vulnerabilities should be reported according to [SECURITY.md](SECURITY.md), not through a public issue.
